# Проверка версии 1.2.0 — 18 октября 2026

Локальные проверки выполнены на Windows с .NET Framework, на отдельной копии файлов. Установленная игра при сборке релиза не изменялась.

- Построены все 3072 комбинации рецептов: 512 для 1.0.13, 512 для 1.0.14, 2048 для 1.0.17. Интерфейс и установщик дополнительно учитывают зависимости галочек.
- Результаты 1.0.13 и 1.0.14 при всех девяти галочках совпадают с прежним патчером.
- DLL 1.0.17 при всех возможностях совпадает побайтно с последним установленным ручным исправлением случайного оружия: `dee7dce16e7c817bb2d1294cd36616d04415f7ef8fd4be2c14ea2c0dce8266e2`.
- Проверены установка, повторное применение, смена галочек и возврат к исходным файлам для всех трёх профилей.
- Режим «L3 — только открытые» не включает обход замков. Режим «L3 — все восемь» работает как отдельная опция, без необходимости включать первую.
- Снятие режима всех восьми удаляет добавленный серверный override. Снятие всех галочек и «Восстановить» возвращают исходные файлы и отсутствие этого override.
- Проверен переход с четырёхфайлового журнала прежнего патчера 1.0.17 и всей последовательности ручных изменений, включая последнее исправление случайного оружия.
- Неизвестная DLL, сторонний override, изменённый после установки скрипт и отсутствующий исходный скрипт приводят к отказу без перезаписи посторонних файлов.
- При блокировке файла во время установки проверены журнал незавершённой записи и последующее восстановление.
- Проверено окно патчера: 11 видимых галочек, альтернативные режимы L3, тестовая опция случайного оружия.
- Ранее для нативного обработчика последнего исправления случайного оружия выполнено 3679 случаев эмуляции: одиночное нажатие, занятые руки, передача/доставание/отпускание, флаги UI, сохранение регистров. Релизный результат содержит тот же машинный код.

Предел проверки: последнее исправление исчезновения рук требует повторного испытания пользователем в VR. Автоматические проверки сборки и файлов не подтверждают отсутствие всех игровых ошибок. Поэтому случайное оружие помечено «тест» и на новой установке выключено по умолчанию.
