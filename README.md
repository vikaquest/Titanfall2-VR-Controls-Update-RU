# Titanfall 2 VR — Quest Custom Patch

Неофициальное дополнение к **Titanfall 2 VR от CircuitLord**: небольшая Windows-программа с галочками для выбора управления и прицела.

**Патчер 1.1.1 поддерживает проверенные сборки VR-мода 1.0.13 и 1.0.14.** Патчер проверяет SHA-256 файлов и отказывается изменять неизвестные сборки.

## Скачать и установить

Скачайте **Titanfall2VR-QuestPatch.exe** из [Releases](https://github.com/vikaquest/TitanFall2_VR_mode_improved/releases/latest). Размер EXE — около 188 КБ; отдельная установка не нужна.

1. Установите **Titanfall 2**.
2. Установите VR-мод через [CircuitLordVRModInstaller](https://github.com/CircuitLord/CircuitLordVRModInstaller). Нужны поддерживаемые файлы VR-мода **1.0.13 или 1.0.14**.
3. Закройте игру и запустите **Titanfall2VR-QuestPatch.exe**.
4. Выберите папку **Titanfall2** и отметьте нужные функции.
5. Нажмите **«Применить выбранное»**, затем запускайте игру обычным способом через VR-инсталлятор.

Требования: **Windows 10/11 x64, .NET Framework 4.8**, контроллеры Quest / Touch. Python, доступ к интернету и отдельный установщик патчера не нужны.

## Изменения на выбор

| Галочка | Что меняется |
| --- | --- |
| Перезарядка на левом Trigger | Магазин, механизм и ручная перезарядка используют левый Trigger. Также включается перенос способности пилота на L3, чтобы освободить Trigger. |
| Способность пилота на L3 | Cloak / соответствующая способность пилота переносится на нажатие левого стика. |
| Область хвата второй рукой ×2 | Увеличивается область поддержки оружия левой рукой. Область взятия оружия правым Grip не меняется. |
| Область перезарядки ×2 | Увеличиваются области магазина, механизма и перезарядки. |
| Граната на правом Trigger | Взятие гранаты возле груди переносится с Grip на правый Trigger. |
| Titan loadout на L3 | Доступные комплекты титана переключаются по кругу только внутри титана, при отпускании L3. |
| Способности титана через кнопки | Левый Grip + Trigger — способность 1; Grip + A — 2; Grip + B — 3; Grip + R3 — ядро. Один Grip способность не запускает. |
| Обмен оружия в кобурах на B | Оружие за спиной и у левого бедра меняется местами, без доставания в руку. Нужны оба убранных оружия, пустые руки и отпущенные остальные кнопки. |
| Точка для стрельбы от бедра | Заполненная белая точка среднего размера, направленная от muzzle оружия. Для гранат и титана не отображается; разброс пуль не показывает. |

Стрельба остаётся на правом Trigger. B с оружием в руке сохраняет перезарядку; Grip + B в титане — способность. X сохраняется для выхода из титана. R3 без Grip сохраняет ближний бой, L3 + R3 — ручной сброс позиции.

## Резервные копии и изменение выбора

Повторно запустите EXE и измените галочки. Результат каждый раз строится из проверенной исходной копии, поэтому патчи не накладываются друг на друга.

- Снятие всех галочек возвращает исходные проверенные файлы VR-мода.
- **«Восстановить»** возвращает состояние до первого применения этого EXE.
- Резервные копии и журнал лежат в **`<папка игры>/.quest-custom-patch`** для 1.0.13 и **`<папка игры>/.quest-custom-patch-1.0.14`** для 1.0.14. Сохраните эту папку для отката.
- После прерванной записи нажмите **«Восстановить»** при следующем запуске.
- Если установленные файлы изменены другой программой или мод обновился, патчер остановится и сохранит копии.

Дополнительно поддерживается импорт строго определённой рабочей сборки с нашими предыдущими ручными изменениями. Это не означает поддержку произвольных сторонних модификаций.

## Ограничения и проверки

Отменённое исправление анимации оружия при выходе из титана не включено: короткая анимация остаётся. Неподтверждённый автоматический сброс позиции и неработавший штатный прицел каждого оружия тоже не включены.

Локально прошли построение всех 1024 комбинаций для двух поддерживаемых версий, эмуляция native-обработчиков кнопок, установка на исходную и нашу предыдущую сборки, повторное применение, восстановление, отказ при изменённых файлах и восстановление после ошибки записи. Исправления перезарядки и прицела для 1.0.14 проверены пользователем в игре и VR-шлеме. При выборе всех галочек патчер создаёт DLL, побайтно совпадающую с этой проверенной сборкой.

## Собрать из исходников

На Windows с установленным .NET Framework:

```powershell
./build.ps1
```

Результат: **`dist/Titanfall2VR-QuestPatch.exe`**. `QuestPatch.cs` содержит интерфейс, проверку файлов, резервное копирование и транзакционную запись. `payload.json` содержит рецепты изменений и добавленный код; для сборки EXE исходные DLL игры не нужны.

Полные файлы игры, исходная DLL VR-мода, локальные игровые тестовые копии и резервные копии в репозитории отсутствуют.
