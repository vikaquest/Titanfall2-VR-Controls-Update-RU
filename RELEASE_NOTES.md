Патчер 1.1.1 поддерживает проверенные файлы **Titanfall 2 VR 1.0.13 и 1.0.14**.

В версии VR-мода 1.0.14 исправлены:

- Взятие магазина и ручная перезарядка на левом Trigger: теперь читается Trigger руки, выполняющей перезарядку.
- Отображение заполненной точки для стрельбы от бедра: восстановлено необходимое условие видимости прицела.

Оба исправления проверены пользователем в игре и VR-шлеме. При выборе всех галочек патчер создаёт DLL, побайтно совпадающую с проверенной сборкой. Остальные функции управления сохранены, настройка автора `tf2vr_toggle_grip` остаётся доступной.

Локальные проверки: все 1024 комбинации выбора для двух версий; обработчики кнопок; независимые Trigger обеих рук; установка, повторное применение, восстановление, обновление с сохранённой резервной копией предыдущей версии, отказ при неизвестных файлах и восстановление после прерванной записи.

Установка: установите игру и поддерживаемый VR-мод через CircuitLordVRModInstaller, закройте игру, запустите **Titanfall2VR-QuestPatch.exe**, выберите папку Titanfall2 и нужные галочки. Существующим пользователям достаточно запустить новый EXE и применить выбранные изменения снова.

Требуются Windows 10/11 x64 и .NET Framework 4.8. EXE автономный: без Python и отдельной установки. Подробности и список управления — в README проекта и приложенном README.txt.
